# ⛑️ YOLO Helmet Detector 🛵

A YOLOv8 object detector that spots whether people in an image are wearing a helmet — trained and compared across two model sizes (**Nano** vs **Medium**) to see how much accuracy you actually gain by going bigger.

---

## 📦 Dataset

- **Source:** [Helmet Wearing and Violation Detection (Kaggle)](https://www.kaggle.com/datasets/moeeznisar/helmet-wearing-and-voilation-detect-using-yolov8), downloaded via `kagglehub`
- **Size:** 629 images, YOLO-format bounding box labels
- **Classes:** `With Helmet`, `Without Helmet`
- Filenames were cleaned (stripped Roboflow's `_png.rf.*` suffixes) and the dataset YAML was rewritten to point at the correct train/val/test image folders before training

---

## 🤖 Models Compared

Two YOLOv8 variants were trained from pretrained COCO weights on the same dataset (50 epochs, image size 640, early stopping with patience 10):

| | 🐣 YOLOv8n (Nano) | 🐘 YOLOv8m (Medium) |
|---|---|---|
| **Parameters** | ~3.2M | ~25.9M |
| **Batch size** | 16 | 8 |

---

## 📊 Test Set Results

| Metric | YOLOv8n | YOLOv8m |
|---|---|---|
| Precision | 0.681 | **0.739** |
| Recall | **0.741** | 0.715 |
| mAP50 | **0.750** | 0.724 |
| mAP50-95 | **0.466** | 0.422 |

---

## 🤔 Why Nano Outperformed Medium

The bigger model didn't win — on overall mAP50 and mAP50-95, the 3.2M-parameter Nano beat the 25.9M-parameter Medium. Likely reasons:

- **Overfitting** — Medium's ~8× parameter count makes it much easier to memorize a dataset of only 629 images rather than generalize
- **Dataset size** — a dataset this small tends to favor smaller, less capacity-heavy models
- **Training schedule** — Medium likely needs more epochs, a lower learning rate, and/or stronger regularization (weight decay, dropout, augmentation) to make good use of its extra capacity

Medium did edge out Nano on precision for both classes and on recall for "Without Helmet" — so the trade-off isn't one-sided, but it's a good reminder that a bigger backbone isn't automatically the better choice on a small, task-specific dataset. 🧭

## 🚀 Running the Notebook

This notebook is written for **Google Colab** and expects a Google Drive mount for storage:

1. Open the notebook in Colab
2. Run the Drive-mount cell and authorize access
3. The dataset downloads automatically via `kagglehub` (requires Kaggle credentials configured in your environment)
4. Run the cleanup cells to normalize filenames and fix the dataset YAML paths
5. Install Ultralytics: `pip install ultralytics`
6. Run the training cells for YOLOv8n and/or YOLOv8m

To run locally instead of on Colab, replace the Drive-mount cell and the hardcoded `/content/drive/...` paths with a local project directory.
